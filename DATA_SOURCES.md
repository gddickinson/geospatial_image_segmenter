# Data sources

| File | Source | Licence |
|---|---|---|
| `test_data/sample.tif` | Synthetic, generated by `scripts/make_sample_data.py` (seed 2026) from `geo_segmenter/utils/synthetic_scene.py`: 1001 x 1001 px, 3 bands (red, green, blue, reflectance x 10000), uint16, 10 m pixels, georeferenced in WGS 84 / UTM zone 31N (EPSG:32631). The CRS and origin only make it a valid GeoTIFF; the scene does not show that place. | Part of this repository (MIT, see LICENSE); no third-party data |
| Web demo scene (`/api/demo`, static site) | Synthetic, `utils/synthetic_scene.make_scene(256, 7)` | Part of this repository (MIT) |
| `tests/fixtures/*.json` | Generated by `scripts/make_web_fixtures.py` from the synthetic scene and seeded random arrays | Part of this repository (MIT) |

Not in the repository: `geo_segmenter/gui/temp/map_capture.tif` is written at runtime by
the map tab's **Capture as Layer** button (a render of the current base-map view; base-map tiles keep their providers' terms) and
is git-ignored. Regenerate the sample with `python scripts/make_sample_data.py`.
